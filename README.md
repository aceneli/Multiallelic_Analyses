# Multiallelic Analysis Steps



### Steps for generating the counts, proportions bar plots and map:

1. Allele frequencies (AF) are computed from vcf files using VCF tools (Allele frequency computation script).
2. Allele frequency columns (AF1, AF2, AF3 & AF4) from the frq files are summed up and saved as csv files (Allele frequency sum ups script).
3. Sum up of the different AF combinations which represent the triallelic and tetrallelic counts (Allele frequency sum ups script).
4. Generation of AF proportions and counts map plot (Proportions, counts map and bar plots generation script).
